The compact model was downloaded from the author's public GLB endpoint. The iPhone GLB came from the public `quentin-pla/phone-mockup-studio` repository at commit `9908f2c321787779b6e028cba1ab67cd29a6a6dd`, path `source/apple_iphone_15_pro_max_black(2).glb`. That mirror's credits incorrectly associate this filename with a different Sketchfab model/author. The actual GLB's embedded attribution identifies **polyman Studio**, model `df17520841214c1792fb8a44c6783ee7`; the original Sketchfab API metadata independently confirms the title, author and CC Attribution licence. Its saved response is `polyman-original-metadata.json`. Runtime credits follow that evidence, not the mirror's mistaken row.

`tools/prepare-imported-phones.py` flattens source transforms, centers/normalizes the model, rotates the iPhone to face +Z, batches by original material, and exports unchanged original embedded map bytes. The complete original mesh topology is retained in the prepared binary: 7,610 triangles for Compact and 64,229 for iPhone. Transmissive front-cover batches are omitted at rendering so project UI remains legible; screen geometry uses the project artwork. Per-file material and binary hashes are in each JSON manifest. No new phone chassis is constructed in JavaScript.

The renderer uses the original base-color, normal, metallic and roughness maps. It uploads detailed material maps at a maximum of 1024px with mipmaps. Source maps whose channels vary by at most 1/255 use 64px; completely uniform maps use one texel. These per-texture runtime LOD limits are recorded in the manifests. Original source files and the project's full-resolution UI artwork are preserved. The estimated RGBA8 material-map allocation including mipmaps falls from about 365.7 MiB at original sizes to 77.2 MiB. This is a format-based estimate, not a driver-reported allocation. Upload work yields between small slices. The author's source PBR model is approximated by the portfolio's own WebGL shader; clearcoat/transmission extensions are not reproduced. Both variants share one renderer and one cached instance per variant in the existing WebGL context. All resources are released on context loss or non-persisted pagehide.

Reproduce the prepared buffers with `python tools/prepare-imported-phones.py` (Python, NumPy and Pillow). These are development-only tools; the deployed runtime remains HTML/CSS/JavaScript plus static assets.
