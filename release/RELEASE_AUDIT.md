# Release audit

The release derives exclusively from the original `site` working directory, including its uncommitted updates and required untracked assets. No code was merged or copied from another worktree. The canonical publication checkout is `site-publication`, branch `release/production`; legacy Git metadata remains in `site` to preserve its linked mobile worktree. The sibling worktree's source files were untouched, and its original HEAD still resolves.

## Independent review

Two independent source/release reviewers inspected actual files, hashes, HTTP behavior, asset provenance, image pixels and history. Their findings led to restoration of the missing CSS fallback image, removal of a stale credits-gallery link, addition of GSHHG/Basemap notices, correction of credits punctuation, safer prevalidated builds, proper test-process error propagation and a production-default browser target. An independent fresh checkout reproduced the full output and all controller tests.

Detailed results, screenshots, resource traces, before/after measurements and review evidence are stored outside the repository in the recovery directory. See [local recovery](LOCAL_RECOVERY.md), [cleanup](CLEANUP_REPORT.md), [performance](PERFORMANCE_REPORT.md), [assets](ASSET_MANIFEST.md) and [publication](DEPLOYMENT.md).

Final-build regression and measured asset comparisons pass. The final local publication commit/tag and clean-history audit identify this report set; local release preparation is complete. External deployment and physical-device checks are intentionally manual follow-up gates, not fabricated successes.
