# 14 / Kira dock

Reference: supplied Office & Communications diagram. Implemented in room.js unless an existing shared component is identified below. Coordinates are room-local metres unless marked world.

Build: Build a shallow graphite charging pad, red edge strips and two metal contacts. Connect its status indicator to the shared Kira route state.

Placement: Room-local [3.5, 0, -0.8]; charging group uniformly scaled to 75%. The pad is 1.065 × 1.005 m with a 0.04875 m top. The attached charging cabinet scales with it. Kira's root height includes the pad height as it parks.

Reuse and budget: The dock contains no robot mesh. Status illuminates when the existing robot reaches this destination.

Verification: Check Kira's wheels meet the pad and the indicator reflects actual arrival.
